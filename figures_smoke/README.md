# Smoke-run figures — SYNTHETIC DATA, NOT RESULTS

Everything in this directory was generated by the CPU smoke run
(`configs/smoke.yaml` + `configs/smoke_seq_only.yaml`) on **synthetic windows**:
4,096 bp windows, 32×32 maps, made-up sequence, and a made-up ATAC channel that
is pure noise.

They exist to demonstrate that the pipeline runs end to end — prepare → train
both arms → evaluate → ablation → figures — and to let you see the figure
layouts before committing GPU time. **No biological claim can be read off them.**

Two things they do usefully show:

* The ablation reports **no significant effect** of the ATAC channel here, with
  confidence intervals spanning zero. That is the correct answer: the synthetic
  ATAC channel carries no information. A pipeline that manufactured a positive
  delta on this input would be broken, and this is the cheapest way to check it
  is not.
* The `predicted` panels are nearly flat while `observed` has clear off-diagonal
  structure — a 2-epoch model on random sequence has learned little beyond the
  mean, exactly as expected.

Real figures land in `figures/` after training on ENCSR830NVY + ENCSR637XSC.
